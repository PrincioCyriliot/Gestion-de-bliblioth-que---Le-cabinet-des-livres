# Exercices Java - API Streams & Lambdas

Ce dépôt contient une série d'exercices pratiques réalisés en Java, se concentrant sur l'utilisation des **Expressions Lambda** et de l'**API Stream** (introduites depuis Java 8). Ces programmes illustrent des manipulations de données efficaces et modernes.

---

## 📂 Contenu des exercices

Chaque classe `ExerciceX` correspond à une thématique spécifique de manipulation de flux :

| Exercice | Thématique | Concepts clés |
| :--- | :--- | :--- |
| **Exercice 1** | Opérations de base | Interface fonctionnelle, Expressions Lambda |
| **Exercice 2** | Manipulation de Listes | `filter()`, `map()`, `sorted()`, `count()` |
| **Exercice 3** | Analyse de Notes | Moyenne, `max()`, `Comparator.reverseOrder()` |
| **Exercice 4** | Gestion de Produits | Objets, `Collectors.groupingBy()`, `averagingDouble()` |
| **Exercice 5** | Gestion d'Étudiants | `partitioningBy()`, regroupements complexes, tri par objets |

---

## 🛠️ Concepts Techniques utilisés

*   **Expressions Lambda** : Pour simplifier l'implémentation des interfaces fonctionnelles.
*   **Stream API** : Pour traiter des collections de données de manière déclarative.
*   **Collectors** : Utilisation avancée pour le regroupement (`groupingBy`) et le partitionnement (`partitioningBy`) des données.
*   **Comparateurs** : Tri personnalisé d'objets via `Comparator`.
